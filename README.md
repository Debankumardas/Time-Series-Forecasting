# Time-Series Forecasting with ARIMA / SARIMA

An end-to-end time-series forecasting project analyzing historical demand trends, seasonality, stationarity, and future demand using statistical forecasting techniques.

## Project Status

🚧 In Progress

## Dataset

Daily demand time-series data provided as part of an internship project.

## Planned Techniques

- Time-Series Decomposition
- Augmented Dickey-Fuller (ADF) Test
- Differencing
- ARIMA / SARIMA
- Hyperparameter Selection
- RMSE
- MAPE
- 30-Day Forecasting
